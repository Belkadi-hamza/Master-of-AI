# Firestore Database Setup Guide

This document describes the Firestore collections and structure needed for the School Manager application.

## Collections Structure

### 1. `profiles` Collection
Stores user profile information.

**Document ID**: User's Firebase UID (from auth)

**Fields**:
```typescript
{
  user_id: string;           // Firebase user UID
  full_name: string | null;
  email: string | null;
  grade_level: string | null;
  avatar_url: string | null;
  created_at: Timestamp;
  updated_at: Timestamp;
}
```

### 2. `user_roles` Collection
Stores user roles (admin/student).

**Document ID**: User's Firebase UID (from auth)

**Fields**:
```typescript
{
  user_id: string;           // Firebase user UID
  role: 'admin' | 'student';
  created_at: Timestamp;
}
```

**Note**: To make a user an admin, create/update a document in `user_roles` with `role: 'admin'`

### 3. `grades` Collection
Stores student grades.

**Document ID**: Auto-generated by Firestore

**Fields**:
```typescript
{
  student_id: string;        // Firebase user UID of the student
  subject: string;
  grade: number;             // 0-100
  term: string;
  created_at: Timestamp;
}
```

## Firestore Indexes Required

You need to create composite indexes in the Firebase Console for the following queries:

1. **Grades Collection**:
   - Index on: `student_id` (Ascending) + `created_at` (Descending)
   - Collection: `grades`
   - Query scope: Collection

2. **Profiles Collection**:
   - Index on: `created_at` (Descending)
   - Collection: `profiles`
   - Query scope: Collection

## Security Rules (Firestore Rules)

Here's a basic security rules configuration. Update these in Firebase Console > Firestore Database > Rules:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Helper function to check if user is authenticated
    function isAuthenticated() {
      return request.auth != null;
    }
    
    // Helper function to check if user is admin
    function isAdmin() {
      return isAuthenticated() &&
        exists(/databases/$(database)/documents/user_roles/$(request.auth.uid)) &&
        get(/databases/$(database)/documents/user_roles/$(request.auth.uid)).data.role == 'admin';
    }
    
    // Helper function to check if user owns the document
    function isOwner(userId) {
      return isAuthenticated() && request.auth.uid == userId;
    }
    
    // Profiles collection
    match /profiles/{profileId} {
      allow read: if isAuthenticated() && (isOwner(profileId) || isAdmin());
      allow create: if isAuthenticated() && isOwner(profileId);
      allow update: if isAuthenticated() && (isOwner(profileId) || isAdmin());
      allow delete: if isAdmin();
    }
    
    // User roles collection
    match /user_roles/{userId} {
      allow read: if isAuthenticated() && (isOwner(userId) || isAdmin());
      allow create: if isAuthenticated() && isOwner(userId);
      allow update, delete: if isAdmin();
    }
    
    // Grades collection
    match /grades/{gradeId} {
      allow read: if isAuthenticated() && (
        isOwner(resource.data.student_id) || isAdmin()
      );
      allow create, update, delete: if isAdmin();
    }
  }
}
```

## Setting Up an Admin User

To create an admin user:

1. Sign up a user through the application
2. Go to Firebase Console > Firestore Database
3. Find the `user_roles` collection
4. Create or update the document with the user's UID
5. Set the `role` field to `'admin'`

Or programmatically in the Firebase Console console:

```javascript
// Run this in Firebase Console > Firestore > Data
db.collection('user_roles').doc('USER_UID_HERE').set({
  user_id: 'USER_UID_HERE',
  role: 'admin',
  created_at: firebase.firestore.FieldValue.serverTimestamp()
});
```

## Authentication Setup

The application uses Firebase Authentication. Make sure:

1. Email/Password authentication is enabled in Firebase Console
2. Authentication is properly configured in `src/integrations/firebase/config.ts`
