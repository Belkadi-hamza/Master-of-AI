# Modele (Data & Notebooks)

This folder contains the datasets, notebooks, and trained model artifacts used for football match outcome classification.

## Contents

- Data/: CSV datasets used for training and evaluation
- API.ipynb: notebook with API-related experiments and model loading
- data_collection.ipynb: data acquisition and preparation steps
- Data-Manipulation.ipynb: feature engineering and cleaning
- models/: exported model artifacts and metadata

## Model artifacts

The models/ directory includes:
- best/: best-performing model artifacts
- feature_names/: saved feature list
- label_mapping/: class label mapping

## Notes

- Notebooks were created in a research workflow and may assume a local or Colab environment.
- Exported artifacts are used by the FastAPI backend in Back-End/.
