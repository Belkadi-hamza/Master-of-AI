### Windows

* **Créer** : python -m venv .venv
* **Activer** : .venv\\Scripts\\activate
* **Désactiver** : deactivate
* **Supprimer** : rmdir /s /q .venv

### macOS / Linux

* **Créer** : python3 -m venv .venv
* **Activer** : source .venv/bin/activate
* **Désactiver** : deactivate
* **Supprimer** : rm -rf .venv
